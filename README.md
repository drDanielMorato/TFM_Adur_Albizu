# TFM_Adur_Albizu
TFM de Adur Albizu sobre análisis de trazas de la UPNA en busca de escaneos de puertos.

## 0. Versionado
| Versión (Readme)| Fecha de modificación | Autor
|---|---|---|
| 0.1 | 04.07.2026 | Adur Albizu

## 1. Estructura del repositorio

Este repositorio tiene dos directorios principales, **cada uno con su respectivo `README.MD`** a modo de guía.

| Directorio | Contenido |
|---|---|
|Extracción| Contiene el script de extracción de registros de flujo a partir de archivos .pcap.| 
|Análisis| Contiene el script de análisis para detectar escaneos a partir de los ficheros obtenidos mediante el script de extracción|
